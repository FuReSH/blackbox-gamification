# blackbox-gamification

This is a simple HTML/Javascript application that uses three examples to convey an understanding of so-called *tool literacy* in the humanities and cultural sciences.

The examples follow the concept of digital tools as black boxes that are opened in order to understand the instrumental and methodological functionality.

The three black boxes are:
- Counting words based on the [American Standard Code for Information Interchange (ASCII)](https://de.wikipedia.org/wiki/American_Standard_Code_for_Information_Interchange)
- Counting words based on [stop words in a stop list](https://en.wikipedia.org/wiki/Stop_word)
- Sorting a list of random numbers in ascending order using the [Slowsort sorting algorithm](https://en.wikipedia.org/wiki/Slowsort)

The application can be extended modularly with further black boxes.
